How to type for best results:

The script hides short vowels, so the scanner considers every plausible reading and lets the meter choose, like a reader would. Two things help it: write tashdīd ّ where a letter is doubled (مدّت، قصّہ، امّید), and write zer ِ for an iẓāfat you'd pronounce (غمِ دل). Everything else is automatic.
